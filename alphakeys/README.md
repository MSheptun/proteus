# AlphaKeys — клавиатура для Android

Форк открытой клавиатуры **[HeliBoard](https://github.com/HeliBoard/HeliBoard)** (GPL-3.0) с тремя доработками.
Это **не** переделка Gboard или Яндекс Клавиатуры: их приложения проприетарные, их нельзя модифицировать и
перепаковывать, поэтому ни их код, ни темы, ни ресурсы здесь не используются.

## Что добавлено

| Что | Как |
|---|---|
| Смена языка свайпом по пробелу | горизонтальный свайп по пробелу по умолчанию = «Сменить язык» (раньше — курсор). Включайте языки в *Настройки → Языки и раскладки*. Дистанцию можно менять: *Дополнительно → Расстояние свайпа для смены языка* |
| Тактильный отклик | свой движок `HapticEngine.kt`: стили Адаптивный / Мягкий / Чёткий / Сильный / Системный, разный отклик для букв, пробела, Backspace, Enter, долгого нажатия; на Android 10+ используются штатные эффекты TICK/CLICK/HEAVY_CLICK, на старых — вибрация с амплитудой. Включён по умолчанию. *Настройки → Предпочтения → Стиль тактильного отклика* (при выборе играет образец). Лёгкий отклик при смене языка |
| 13 новых тем | 10 в цветах легионов Warhammer 40K (Blood Angels, Ultramarines, Iron Warriors, Space Wolves, Dark Angels, Imperial Fists, Alpha Legion, Adeptus Mechanicus, Death Guard, Black Templars) + Neon Night, Amber Terminal, Midnight Glass. Только цвета, выбранные мной; логотипов и графики Games Workshop нет. *Настройки → Оформление → Тема* |
| Имя и значок | AlphaKeys, `com.msheptun.alphakeys` (ставится рядом с HeliBoard, провайдеры тоже переименованы), свой значок |

Превью палитр (схема, не скриншот): `docs/themes-palette.png`.

## Сборка

```
alphakeys/scripts/build.sh /tmp/alphakeys-src
```

Нужны JDK 21+, Android SDK (platform 37, build-tools 37, NDK 28.0.13004108). `MAVEN_CENTRAL_MIRROR=...` — если Maven Central отвечает 429.
Либо GitHub Actions → *Build AlphaKeys (Android keyboard)* → артефакт `AlphaKeys-apk`.
APK подписан debug-ключом (для теста). Для раздачи подпишите своим ключом.

Состав: `UPSTREAM` (HeliBoard на конкретном коммите), `patches/0001-alphakeys.patch`, `scripts/`.
