# Постоянная память Claude

## О пользователе
- Язык общения: русский
- Интересует курс кыргызского сома (KGS) к рублю (RUB)

## Инструменты на этом ПК
- git 2.43.0, Python 3.11, pip3, curl — всё уже установлено
- `/usr/local/bin/rate` — скрипт для курсов валют: `rate KGS RUB`
- Доступ к интернету есть, нужно явно использовать при реал-тайм вопросах
